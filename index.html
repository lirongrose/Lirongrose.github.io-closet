放到手机桌面，下次一点就开

iPhone：用 Safari 打开本页 → 底部「分享」→ 下滑选「添加到主屏幕」→ 完成。
安卓：用浏览器打开本页 → 右上角「⋮」→ 选「添加到主屏幕 / 安装应用」。
微信里打开的话：先点右上角「⋯」→「在浏览器打开」，再按上面步骤加。
加好后桌面会出现「收纳管家」图标，点开就是全屏，跟 App 一样，不用再扫码。数据仍存在本机，换手机/清缓存前记得导出备份。

怎么用

1. 衣柜页点「上传照片/衣柜设置」→ 拍照或选照片；已有照片可直接用顶部编辑工具条。
2. 编辑工具条：选中/改形状=点格子后拖红圆点微调（可改名/删除）；画格子=沿隔板点几个点画任意斜边格；分割=在格子上拖线切成两块；合并=点一个格子，相邻格子会亮起，再点几个（至少两个）→「合并选中」。改完点「收纳」回到正常模式。
3. 右下角 + → 拍摄/选择衣物照片，填名称品类季节。
4. 「衣柜」页点衣物拎出，再点柜格放入；点衣物详情可取出（自穿/借出/清洗）或放回。
5. 看细节：双指捏合以手指为中心放大缩小，单指拖动把某个角落拖到屏幕中间再看；也可点「＋放大 / －缩小 / 适应屏幕」。放大后仍可直接画格子。
6. 首页按品类 + 季节 + 状态组合筛选，快速找到某件衣服。
